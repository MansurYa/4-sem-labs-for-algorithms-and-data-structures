### 🔵 Обработка данных (Lab4)
**Ключевая проблема**: Восстановление 15-30% пропусков в студенческих данных  
**Метод-победитель**: Стохастическая регрессия 

```bash
python data_processor.py \
  --input student_data.csv \
  --method stochastic \
  --missing 0.2 \
  --output results.csv
```

| Метод восстановления | Погрешность (ε) |
|----------------------|-----------------|
| Стохастическая регрессия | 2.8%          |
| Линейная регрессия   | 4.1%           |
| Заполнение средним   | 7.2%           |

> **Ключевой инсайт**: Комбинация регрессионных моделей с генератором случайных возмущений дает минимальную погрешность при восстановлении разнородных данных.

---

### 🔵 Кластерный анализ (Lab5)
**Ключевая проблема**: Эффект цепочки в односвязывающей кластеризации  
**Метрика**: Индекс Фоулкса-Мэллова  

```math
\Delta FM = \frac{|FM_{\text{orig}} - FM_{\text{anonym}}|}{FM_{\text{orig}}} \times 100\% = 41.58\%
```

**Сравнение методов**:
| Метод             | Время (1000 точек) | Индекс FM |
|-------------------|--------------------|-----------|
| K-means (+SPA)    | 0.18 с             | 0.947     |
| Односвязывающий   | 15.3 с             | 0.583     |

> **Фундаментальный вывод**: Односвязывающий метод принципиально неприменим для данных без выраженной кластерной структуры.

## Практические рекомендации
1. **Оптимизация маршрутов**: 
   - Городская логистика: Модиф. сосед + GPU-ускорение
   - Межрегиональные перевозки: Гибрид муравьиного алгоритма и отжига

2. **Защита данных**: 
   - K-анонимность с гарантией ≥5 для квази-идентификаторов
   ```math
   \max(\text{sensitivity}) \leq \frac{\sigma^2}{n-1}
   ```

3. **Прогностика**: 
   - Использовать SPA-выбор признаков перед кластеризацией
   ```python
   from feature_selection import SPASelector
   selector = SPASelector(data, n_features=3)
   features = selector.fit()
   ```
